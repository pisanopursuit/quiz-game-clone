# Quiz Game VS Clone

## Project Overview

Quiz Game VS Clone is a recreation of the Quiz Game VS browser game. The project is being developed as a collaborative software engineering exercise focused on building a functional quiz-based game experience while practicing modern development workflows, Git collaboration, pair programming, and agile development principles.

Original Game:
https://plays.org/game/quiz-game-vs/

## Project Goal

The goal of this project is to build a fully functional clone of Quiz Game VS that allows users to answer trivia questions, compete for points, track progress, and enjoy an engaging quiz game experience.

This project is being built as part of a collaborative development program and serves as both a technical learning exercise and a portfolio project.

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project:

```bash
cd quiz-game-vs-clone
```

Install dependencies (if applicable):

```bash
npm install
```

Run the application:

```bash
npm start
```
